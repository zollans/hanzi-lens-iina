# Third-party data and media

The MIT licence in `LICENSE` covers the plugin's code only. The files in `ui/data/` and `ui/strokes/` are generated by `tools/build_dict.py` from the sources below and remain under those sources' licences. If you redistribute them, keep this file and the texts in `licenses/`.

| Data | Source | Licence | Where it ends up |
| --- | --- | --- | --- |
| Word definitions and readings | [CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cc-cedict) (MDBG) | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) | `ui/data/words.js` |
| Cantonese readings | [CC-Canto](https://cantonese.org/download.html) | [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) | `ui/data/words.js`, `ui/data/chars.js` |
| HSK levels | [complete-hsk-vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary) | MIT | `ui/data/words.js` |
| Word frequencies | [jieba](https://github.com/fxsjy/jieba) `dict.txt.big` | MIT | `ui/data/words.js` |
| Character readings, glosses, variants, stroke counts | [Unicode Unihan database](https://www.unicode.org/charts/unihan.html) | [Unicode License v3](https://www.unicode.org/license.txt) | `ui/data/chars.js` |
| Character decomposition and etymology | [Make Me a Hanzi](https://github.com/skishore/makemeahanzi) `dictionary.txt` | LGPL-3.0-or-later (`licenses/LGPL-3.0.txt`, `licenses/MAKE-ME-A-HANZI-COPYING.txt`) | `ui/data/chars.js` |
| Stroke geometry | [hanzi-writer-data](https://github.com/chanind/hanzi-writer-data), from Make Me a Hanzi and the Arphic fonts | Arphic Public License (`licenses/ARPHIC-PL.txt`) | `ui/strokes/*.js` |
| Example sentences | [Tatoeba](https://tatoeba.org) | [CC BY 2.0 FR](https://creativecommons.org/licenses/by/2.0/fr/) | `ui/data/examples.js` |

The data files are modified from the originals: fields are selected, merged and re-encoded into compact JavaScript bundles. Because CC-CEDICT and CC-Canto are share-alike, `ui/data/words.js` and `ui/data/chars.js` are distributed under CC BY-SA 4.0.
